Import Custom Keys

Upload your own Tor v3 Ed25519 hidden service keys to use a vanity .onion address. Generate keys with a tool like mkp224o.

How to generate vanity keys

  1. Install mkp224o on a machine with good CPU
  2. Run: mkp224o -n 1 -d output_dir yourprefix
  3. This will create a directory named with the .onion address containing three files
  4. Upload hs_ed25519_secret_key and hs_ed25519_public_key above
  5. Longer prefixes take exponentially longer (~32x per character). 1-4 chars: seconds to minutes. 5+ chars: hours to days.
